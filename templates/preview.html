Architecture

How VoltFlow Is Built

A clean, modular architecture designed for maintainability and performance.

01

Frontend

A responsive SPA-like experience built with vanilla HTML, CSS, and JavaScript — no heavy frameworks needed.

  • Modular JS architecture (Auth, Map, Stations, Booking, Wallet modules)
  • Leaflet.js for interactive mapping
  • Dark/Light theme support
  • Glassmorphism design system
  • Mobile-first responsive layout
02

Backend

Python Flask powers the RESTful API with session-based auth and clean route organization.

  • Flask REST API with 25+ endpoints
  • Session-based authentication
  • Role-based access control (User, Station Admin)
  • Auto-seeding with demo data
  • DB migration support
03

Database

SQLite provides a zero-configuration, embedded database with a rich relational schema.

  • 9 tables: users, stations, chargers, bookings, payments, reviews, wallet, offers, workers
  • Foreign key relationships
  • Aggregation queries for analytics
  • Auto-initialization with demo data

Project Details

Under the Hood

A deeper look at VoltFlow's capabilities and API design.

User Roles & Access

VoltFlow supports two distinct user roles with separate interfaces and permissions:

  • EV Driver — Browse stations, book chargers, manage vehicles, earn & redeem wallet points, write reviews
  • Station Owner — Manage station info, add/remove chargers, handle bookings, manage workers, track revenue, create promotional offers

API Endpoints

VoltFlow exposes a comprehensive REST API with 25+ endpoints:

POST /api/login POST /api/register GET /api/stations GET /api/stations/:id POST /api/bookings POST /api/payments GET /api/wallet POST /api/reviews GET /api/profile PUT /api/profile GET /api/vehicles POST /api/vehicles DEL /api/vehicles/:id GET /api/station-admin/stats POST /api/station-admin/chargers GET /api/station-admin/workers

Data Model

9 interconnected tables model the entire EV charging ecosystem:

  • Users — Profiles, roles, wallet points, vehicle preferences
  • Stations — Location, amenities, ratings, operating hours, contact
  • Chargers — Type, power (kW), pricing, real-time status
  • Bookings — Scheduling, references, status lifecycle
  • Payments — Transaction history, method tracking
  • Reviews — Ratings, comments, auto-aggregation
  • Wallet — Points ledger, earn/redeem tracking
  • Offers — Station promotions, point costs
  • Workers — Staff assignments, shifts, performance

Key Capabilities

  • Real-time Availability — Charger status updates automatically when booked or freed
  • Gamified Rewards — Vehicle-type-based point earnings (80 pts for cars, 50 pts for scooters)
  • Multi-Vehicle Support — Register, manage, and switch between multiple EVs
  • Station Self-Service — Owners can create stations, add chargers, and go live independently
  • Worker Management — Assign bookings to workers, track performance per shift
  • Dark/Light Theme — Full theme support with smooth transitions
  • Demo Mode — Pre-seeded data with 8 stations across India for instant exploration
